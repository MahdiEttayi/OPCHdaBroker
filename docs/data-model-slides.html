This document presents a unified view of the OPC HDA Broker's data architecture, combining:

Program Phase: C# classes that handle OPC HDA data in memory

Summary

Slide 10 of 10

Key Takeaways

1. TsdbDataPoint bridges OPC HDA data to TimescaleDB
2. BackfillService handles historical data import in configurable chunks
3. hda_data hypertable provides time-series optimized storage
4. Primary key on (time, tag) enables deduplication via ON CONFLICT DO NOTHING
5. TimescaleDB's automatic chunking ensures efficient queries on large datasets
